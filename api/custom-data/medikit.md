# Medikit

**Properties**

| Property | Type    | Description                                    |
| -------- | ------- | ---------------------------------------------- |
| `Health` | `float` | The amount of health that will be regenerated. |

**Example:**

```yaml
CustomItemType: Medikit
CustomData:
  health: 100.0
```
