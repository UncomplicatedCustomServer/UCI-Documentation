# SCP-207

| Property             | Type    | Description                                             |
| -------------------- | ------- | ------------------------------------------------------- |
| `InstantHealth`      | `float` | How much health is gained after consuming.              |
| `BypassMax`          | `bool`  | Whether to allow the 207 effect intensity to go past 4. |
| `StaminaGain`        | `float` | The stamina that is immediatly gained after consuming.  |
| `Apply207Effect`     | `bool`  | Whether to apply the SCP-207 effect.                    |
| `RemoveItemAfterUse` | `bool`  | Whether to remove the item after use.                   |

**Example:**

```yaml
CustomItemType: SCPItem
Item: SCP207
CustomData:
  instant_health: 50
  bypass_max: true
  stamina_gain: 100
  apply207_effect: true
  remove_item_after_use: false
```
