# SCP-500

| Property               | Type    | Description                                                      |
| ---------------------- | ------- | ---------------------------------------------------------------- |
| `AllowAchievement`     | `bool`  | Whether to allow the user to get the Crisis Averted achievement. |
| `ApplyHeal`            | `bool`  | Whether to apply the healing effect.                             |
| `InstantHealth`        | `int`   | The health that is immediatly gained after consuming.            |
| `RegenSpeedMultiplier` | `float` | The speed multiplier for the regen.                              |
| `HPGainMultiplier`     | `float` | The HP gain multiplier for the regen.                            |

**Example:**

```yaml
CustomItemType: SCPItem
Item: SCP500
CustomData:
  allow_achievement: false
  apply_heal: true
  instant_health: 100
  regen_speed_multiplier: true
  hp_gain_multiplier: false
```
